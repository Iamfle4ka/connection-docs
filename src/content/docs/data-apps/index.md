Apps are interactive web applications that use data to deliver insights or take action. They run inside your Keboola project and are reachable from a public URL, so the people who use them do not need a Keboola account.

## Why build apps?

Apps give your organization purpose-built interfaces that solve specific business problems: custom dashboards that replace traditional BI tools, self-service tools for non-technical users, and targeted solutions such as recommendation engines or approval workflows. [Read more about what apps are and when to use them](/data-apps/what-are-apps/).

## Choose how you build

There are three ways to build an app in Keboola. Pick the one that fits your team and use case.

- **[Build with Kai](/data-apps/build-with-kai/)** — build a Python/JS app with an AI assistant. The recommended path for most custom apps: you describe what you want, and Kai generates the repository structure and configuration for you.
- **[Build locally](/data-apps/build-locally/)** — write and run a Python/JS app on your own machine, then connect it to Keboola data through Input Mapping, the Storage API, or Storage Access.
- **[Streamlit](/data-apps/streamlit/)** — build a Python app with the Streamlit framework. A supported, specialized path that is the fastest way to ship dashboards and internal tools.
